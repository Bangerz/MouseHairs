# MouseHairs (Mouse Sonar)

WoW **retail** add-on: a **cursor “sonar”** — crosshair lines and an optional pulse at the mouse, with keybind (`Find Mouse`) and `/pulse`. Options include always-visible mode, combat/raid-only, mouselook behavior, colors, and hollow vs solid circle.

## Upstream & credit

- **Author (per `.toc`):** Castleguard  
- In-game options frame is labeled **“Mouse Sonar Options”**; bindings use **“Mouse Sonar”** / **Find Mouse**.

This tree is a **CC0 publication** of the add-on sources and assets maintained by **[Bangerz](https://github.com/Bangerz)**. If you know a canonical **CurseForge / Wago / original repo** link for Castleguard’s release, open an issue or PR to add it here.

## Repository

**[github.com/Bangerz/MouseHairs](https://github.com/Bangerz/MouseHairs)**

```bash
git clone https://github.com/Bangerz/MouseHairs.git
```

Copy the `MouseHairs` folder into `World of Warcraft\_retail_\Interface\AddOns\`.

## Files

- `MouseHairs.lua` — logic and Settings/Interface options  
- `Bindings.xml` — keybind to pulse/show the cursor marker  
- Textures: `Circle_White.tga`, `Circle_Hollow.tga`, `horizontal.BLP`, `vertical.BLP`, etc.
